## 本周概览

本周主要围绕 **小样本条件下固体火箭发动机跨型号推力曲线预测** 展开实验完善与论文核对。

重点完成了：

- 目标型号 B 的五折留一评估；
- Transformer / MLP、Reptile / Transfer / Scratch 等对照实验；
- 特征身份嵌入消融；
- 贝叶斯优化实验；
- 学习率调度消融；
- 时间轴恢复及峰值推力、冲量和阶段误差等工程指标后处理。

---

## 一、完成五折目标域评估

当前数据设置为：

```text
源型号 A：20 个样本
目标型号 B：5 个样本
源型号 C：18 个样本
每个样本：8 个静态特征 → 800 点推力曲线
```

目标 B 采用五折留一测试：

```text
3 个 support → 目标域适应
1 个 validation → 模型评价 / BO
1 个 held-out test → 最终测试
```

5 个 B 样本轮流作为测试样本，从而得到完整的五折目标域结果。

---

## 二、模型与训练策略对照

本周补齐了多组对照实验，包括：

```text
Reptile-Transformer
Transfer-Transformer
Scratch-Transformer
Reptile-MLP
Transfer-MLP
Reptile-Transformer（无 feature identity embedding）
```

阶段性结果显示：

- Reptile-Transformer 和 Transfer-Transformer 均优于 Scratch-Transformer，说明当前数据条件下利用源型号信息是有效的；
- Reptile-MLP 优于 Transfer-MLP；
- Transformer 与 MLP 的结果表明，Transformer 在当前设置下具有一定精度优势，但计算成本也明显更高；
- 去除 feature identity embedding 后，MSE、RMSE 和 MAE 略有上升，说明该设计提供了一定帮助，但不能解释为物理因果贡献。

---

## 三、学习率消融与贝叶斯优化

### 学习率消融

原配置中的初始和终止内循环学习率均为 `0.001`，因此所谓余弦调度实际上退化成了常数学习率。

本周重新设置：

```text
余弦：0.005 → 0.001
对照：恒定 0.005
```

结果中，余弦调度的 MSE、RMSE 和 MAE 更低，而固定学习率的全局 MAPE 更低，说明不同评价指标之间仍存在权衡。

### 贝叶斯优化

完成 5 折、每折 10 次候选评价的 BO 实验，并保存每折搜索历史。

BO 的全局 MAPE 优于原固定配置，但 MSE、RMSE 和 MAE 更高，因此目前不能简单表述为“贝叶斯优化全面提高预测精度”。

## 四、工程指标后处理

本周找到了 B 型原始推力数据的时间列，并恢复出与 800 点预测曲线对应的时间轴。

当前按降采样程序划分为：

```text
启动阶段：0–99
稳态区间：100–599
尾段：600–799
```

完成了峰值推力、预测窗口内冲量及阶段误差等后处理。

当前原固定配置主模型的五折均值包括：

| 指标 | 结果 |
|---|---:|
| 峰值推力相对误差 | 0.777% |
| 预测窗口内冲量相对误差 | 0.479% |
| 100–599 区间 MAPE | 1.180% |
| 尾段 MAPE | 3.888% |

启动附近存在接近零推力，因此全局 MAPE 容易被放大，后续仍需要结合 RMSE、MAE 和分阶段指标进行综合评价。

## 五、本周发现并修正的问题

本周还集中解决了几个影响实验可信度的问题：

- 修复主实验脚本对 PyCharm 工作目录的路径依赖；
- 发现原学习率消融实际上退化为常数学习率，并重新设计有效对照；
- 将旧稳态评价窗口从 `60–430` 调整为与当前降采样逻辑一致的 `100–599`；
- 明确“降采样分段”不等同于已经严格验证的物理阶段边界；
- 区分固定配置、BO 配置和不同训练策略的计算成本，避免对实验结论作过度表述。
